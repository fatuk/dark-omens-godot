## 🇷🇺 Русская версия

# 0.6.0 — Сборка под macOS и новое письмо со входом

Техническое обновление. Новых механик здесь нет — зато игра впервые собирается под Mac, а вход в неё перестал выглядеть как служебная записка.

## 🍎 macOS

Собирается **универсальная** сборка: и Apple Silicon, и Intel одним приложением, macOS 11+ и 10.12+ соответственно. Приложение подписано ad-hoc — без этого arm64-бинарь на маке просто не запустится.

Из-за Apple Silicon пришлось добавить в игру второй формат сжатия текстур (ASTC): без него Godot отказывается собирать универсальное приложение вовсе. На Windows-сборку это не влияет — туда он не попадает.

Приложение не заверено у Apple, поэтому при первом запуске macOS его не пустит. Это снимается одной командой, она есть в инструкции рядом со сборкой.

**Починено:** на маке было видно два курсора — системный поверх нарисованного. Он прятался единственным вызовом на старте, а macOS скрывает курсор только для окна в фокусе; окно к тому моменту активным ещё не было.

## ✉️ Письмо с кодом входа

Письмо с одноразовым кодом переделано целиком: рамка, эмблема, панорама города и отдельные ячейки под каждую цифру. Раньше это был голый чёрный прямоугольник с числом.

Важное под капотом: код в письме по-прежнему **текст**, а не картинка. Почтовые клиенты по умолчанию блокируют графику, и письмо обязано читаться без неё — иначе оно бессмысленно, ведь открывают его только ради кода. Ещё код не попадает ни в тему письма, ни в строку предпросмотра: и то и другое видно в уведомлении на заблокированном экране.

## 🇬🇧 English version

# 0.6.0 — macOS build and a new sign-in email

A technical release. No new mechanics — but the game now builds for Mac, and signing in no longer looks like an internal memo.

## 🍎 macOS

The build is **universal**: Apple Silicon and Intel in one application, macOS 11+ and 10.12+ respectively. It is ad-hoc signed — without that an arm64 binary simply will not launch.

Apple Silicon forced a second texture compression format (ASTC) into the game: without it Godot refuses to build a universal application at all. The Windows build is unaffected — ASTC never ships there.

The application is not notarized, so macOS will block the first launch. One command clears it; the instructions ship next to the build.

**Fixed:** two cursors on Mac — the system one on top of the drawn one. It was hidden by a single call at startup, but macOS only hides the cursor for a focused window, and the window was not active yet.

## ✉️ The sign-in email

The one-time code email was rebuilt: frame, emblem, city skyline, and a separate cell for every digit. It used to be a bare black rectangle with a number in it.

One thing worth saying out loud: the code is still **text**, never an image. Mail clients block graphics by default, and the email has to read without them — otherwise it is useless, since the code is the only reason anyone opens it. The code also stays out of the subject line and the preview text: both show up in notifications on a locked screen.
