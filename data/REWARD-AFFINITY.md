# Бонусы локаций — `rewardAffinity`

Необязательное поле у локации в `locations.json`. Задаёт **бонус на УСПЕХЕ встречи**
на этой локации: с шансом — доп-эффект поверх результата карточки (улика на поле,
прокачка навыка и т.д.). Тематически отражает «специализацию» места.

> Это **не** способность-действие города (как на печатном поле ДУ), а бонус, который
> иногда «капает» за успешную встречу здесь.

---

## Формат

```jsonc
{
  "id": "Arkham",
  …,
  "rewardAffinity": { "<спецификация>": <вес>, … }
}
```

Локация без `rewardAffinity` → бонусов не даёт.

---

## Спецификация бонуса: `verb` или `verb:param`

| Запись | Что |
|---|---|
| `improveSkill:lore` | прокачать **конкретный** навык (`lore` · `influence` · `observation` · `strength` · `will`) |
| `improveSkill` | прокачать **случайный** навык |
| `gainClue` / `gainClue:2` | +1 (или +N) улика игроку |
| `placeClue` / `placeClue:2` | положить 1 (или N) улику на поле |
| `healSanity:2` / `gainFocus:2` | +N к показателю |
| `gainAsset` | случайный актив |
| `gainSpell` | случайное заклинание |

Параметр после `:` — для `improveSkill` это **навык**, для count/amount-глаголов — **число**
(без числа = 1). Поддержаны только проверенные движком глаголы (выше); неизвестный глагол
станет no-op.

---

## Веса и вероятности — два слоя

**1. Сработает ли бонус вообще** — общий шанс `_LOC_BONUS_CHANCE` (по умолчанию **0.5**)
в `scripts/core/encounter_flow.gd`. В половине успехов бонуса нет.

**2. Какой бонус** (если сработал) — **взвешенный** выбор: вес ÷ сумма весов.

Пример `{ "improveSkill:observation": 3, "gainClue": 1 }` (сумма 4):
- `improveSkill:observation` → 3/4 = **75%**
- `gainClue` → 1/4 = **25%**

Итог на один успех (при шансе 0.5):
- 37.5% → +наблюдательность · 12.5% → +улика · **50% → ничего**.

### Правила
- **Один бонус без альтернативы:** `{ "improveSkill:observation": 1 }` — при срабатывании всегда он.
- **Доминирующий бонус:** увеличь его вес: `{ "improveSkill:observation": 9, "gainClue": 1 }` → 90/10.
- Веса **относительные** (не проценты): важны только пропорции.
- Бонус решается ОДИН раз при переходе в успех (перебросы его не «мигают»); на провале — нет бонуса.
- Сейчас работает только для **flat-встреч** (general/research); для gate/mystery — пока нет.

---

## Текущие примеры (по городам)

| Локация | Баннер на поле | `rewardAffinity` |
|---|---|---|
| San Francisco | Улучшение 👁 | `{ "improveSkill:observation": 3, "gainClue": 1 }` |
| Istanbul | Улучшение 📖 | `{ "improveSkill:lore": 3, "gainClue": 1 }` |
| London | Новые улики | `{ "placeClue": 3, "gainClue": 1 }` |
| Arkham | Заклинания-чары | `{ "gainSpell": 3, "gainClue": 1 }` |
| Buenos Aires | Заклинания-ритуалы | `{ "gainSpell": 3, "gainClue": 1 }` |

Глушь/море баннеров не имеют → `rewardAffinity` им не задаём.
