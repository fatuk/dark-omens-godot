# Сборка и установка под macOS

Статус на 0.5.0: сборка настроена, собирается **с Windows-хоста** и запускается
на маке. Что подтверждено железом, а что нет — в конце файла.

## Для игрока

Короткая версия этого раздела — `docs/macos-install-ru.txt`; `make game-export-mac`
кладёт её рядом с архивом как «Установка на macOS.txt». Правки вносить туда же,
иначе игрок получит устаревший текст.

Скачивается `DarkOmens-<версия>.zip`. Внутри `Dark Omens.app` — universal-бинарь:
работает и на Apple Silicon (M1 и новее, macOS 11+), и на Intel (macOS 10.12+).

1. Распаковать двойным кликом — штатный Архиватор macOS положит рядом
   `Dark Omens.app`. Распаковать **обязательно**: `.app` — это папка-бандл,
   из архива macOS её не запустит.

   Сторонними распаковщиками лучше не пользоваться: в архиве исполняемый файл
   лежит с правами `0755`, но некоторые из них права теряют, и приложение молча
   не стартует. Лечится:

   ```
   chmod +x "/Applications/Dark Omens.app/Contents/MacOS/Dark Omens"
   ```
2. Перетащить `Dark Omens.app` в «Программы».
3. **Первый запуск — обязательный шаг.** Приложение подписано ad-hoc и не заверено
   у Apple (не нотаризовано), поэтому Gatekeeper его не пустит. Снимаем карантин:

   ```
   xattr -dr com.apple.quarantine "/Applications/Dark Omens.app"
   ```

   Это разовая процедура: дальше приложение открывается как обычное.

   Обходы через GUI (правый клик → «Открыть», «Системные настройки» →
   «Конфиденциальность и безопасность» → «Всё равно открыть») намеренно не
   описываем: их поведение разъезжается по версиям macOS — в Sequoia правый клик
   уже не помогает, — а команда выше работает везде и объясняется одной строкой.

4. Если вместо диалога пишет, что приложение **«повреждено и должно быть
   перемещено в Корзину»** — это тот же карантин, а не битая загрузка. Лечится
   командой `xattr` из пункта 3.

**Где лежат данные игры** (настройки, сессия входа, логи):
`~/Library/Application Support/Godot/app_userdata/Dark Omens/`.
Удалить игру = удалить `.app` и эту папку.

## Для сборки

```
make game-export-mac GODOT='C:/Users/fatuk/Godot/Godot_v4.6.2-stable_win64_console.exe'
```

Результат — `build-mac/DarkOmens-<VERSION>.zip`, версия берётся из
`project.godot` (`config/version`).

Ключевые настройки пресета `macOS` в `export_presets.cfg`:

| Настройка | Значение | Зачем |
|---|---|---|
| `binary_format/architecture` | `universal` | Intel + Apple Silicon одним файлом |
| `codesign/codesign` | `1` (встроенная ad-hoc) | без подписи arm64-бинарь не запустится вообще |
| `application/bundle_identifier` | `world.dark-omens.game` | обязателен, иначе экспорт падает |
| `texture_format/s3tc_bptc` | `true` | BC7-арт: карта и фоны встреч |
| `texture_format/etc2_astc` | `true` | **обязателен** для universal/arm64 |

### Грабли

**ASTC обязателен.** Godot прямо отказывается собирать universal или arm64, если
ETC2 ASTC выключен. Нужны оба флага: `texture_format/etc2_astc=true` в пресете
**и** `rendering/textures/vram_compression/import_etc2_astc=true` в настройках
проекта.

**Смена этой настройки не инвалидирует кэш импорта.** Godot не перезальёт
текстуры сам — ни по рескану, ни по `--import`. Пять VRAM-текстур
(`map`, `city`, `sea`, `wilderness`, `yuggoth`) надо переимпортировать вручную:

```
rm .godot/imported/{map,city,sea,wilderness,yuggoth}.png-*.{ctex,md5}
godot --headless --import
```

После этого у каждой текстуры в `.godot/imported/` должно быть **два** файла:
`.bptc.ctex` и `.astc.ctex`. Если ASTC-варианта нет — сборка соберётся, но
текстуры на Apple Silicon поедут битыми.

**`.dmg` с Windows не собрать** — нужен `hdiutil`, он только на маке. Отдаём `.zip`.

**Нотаризация** требует платного Apple Developer ID и мака для `notarytool`.
Пока не делаем — отсюда и пляски с Gatekeeper выше. Если дойдёт до продаж на
маке, нотаризацию стоит поставить в план: она убирает шаг 3 целиком.

**Имя в Finder** берётся из `application/config/name`, а не из имени файла. Оно
же задаёт путь `user://`: переименование проекта уводит каталог данных, и у
установленных копий слетают настройки и сессия входа.

### Статус проверки на железе

Подтверждено запуском 0.5.0 на маке:

- приложение ставится и стартует, снятие карантина через `xattr` работает;
- вход и связь с relay по `wss://` — играбельно, до магазина доходит;
- карта и UI рисуются.

Найдено и в работе:

- **тёмные карточки на витрине магазина.** Витрина — 3D-сцена: квад тени
  `UNSHADED`, а квад карты `SHADED` и держится на двух `OmniLight3D` при
  ambient `0.1`. Похоже, позиционный свет под ANGLE не отрабатывает, и карта
  проваливается до ambient-а. Не подтверждено, чинится.
- **два курсора** — системный не прятался: `Input.set_mouse_mode` звался один раз
  из `_ready()` автолоада, а macOS прячет курсор только для окна в фокусе.
  Починено в `custom_cursor.gd` (переспрашиваем на возврат фокуса, режим
  переставляем принудительно через `VISIBLE` — иначе повторный вызов no-op).

Не проверено отдельно:

- что ASTC-текстуры показываются именно на Apple Silicon (карта видимых артефактов
  не дала, но прицельно не смотрели);
- сборка на Intel-маке.
