DARK OMENS — установка на macOS
===============================

В архиве DarkOmens-<версия>.zip лежит приложение «Dark Omens».
Работает на Apple Silicon (M1 и новее, macOS 11+) и на Intel (macOS 10.12+).
Для игры нужен интернет — она соединяется с сервером.


1. РАСПАКОВАТЬ
--------------
Двойной клик по zip-архиву. Рядом появится «Dark Omens» с иконкой игры.

Распаковать обязательно: изнутри архива приложение не запустится.
Пользуйтесь штатным Архиватором macOS (он и открывается по двойному клику).


2. ПЕРЕТАЩИТЬ В «ПРОГРАММЫ»
---------------------------
Перетащите «Dark Omens» в папку «Программы» (Applications).
Архив после этого можно удалить.


3. ПЕРВЫЙ ЗАПУСК — ОБЯЗАТЕЛЬНЫЙ ШАГ
-----------------------------------
Игра не заверена у Apple, поэтому в первый раз macOS её не пустит.
Это разовая процедура, дальше приложение открывается как обычное.

    xattr -dr com.apple.quarantine "/Applications/Dark Omens.app"


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
«Приложение повреждено и должно быть перемещено в Корзину»
    Это не битая загрузка, а та же защита macOS. Выполните команду
    с xattr из шага 3 — и запускайте снова.

Ничего не происходит при запуске
    Скорее всего архив распаковали сторонней программой, и слетели права.
    Выполните в Терминале:
    chmod +x "/Applications/Dark Omens.app/Contents/MacOS/Dark Omens"


ДАННЫЕ ИГРЫ
-----------
Настройки, вход и логи хранятся здесь:
    ~/Library/Application Support/Godot/app_userdata/Dark Omens/

Чтобы удалить игру полностью — удалите приложение из «Программ»
и эту папку.
