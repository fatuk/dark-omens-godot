# Технический долг: упрощения правил EH

Где игра отыгрывает карту EH не буквально: эффект упрощён, приближён или показан
только текстом. Сверка шла по вики (eldritchhorror.fandom.com). Закрыли пункт —
вычёркиваем отсюда.

Общие правила упрощений:

- **«Вас поглощают»** (devoured) — здоровье падает в 0, дальше обычный Порог, а не
  мгновенное выбывание.
- **«Выбранный сыщик» / «тот сыщик»** в оборотах заклинаний — сам кастующий
  (исключение — цель реакции «Защиты плоти»/«Вселить отвагу», см. ниже).
- **Эффект, которого движок не умеет**, остаётся текстом на карте: игрок его видит,
  но игра его не применяет.

## Заклинания

### Механика

- **Чары (Glamour)**: нет Расплаты с проверкой, как в EH. Каст через истощение
  разыгрывает оборот сразу. Все 4 чар — из дополнений, в сезоне 0 их нет.
- **Касты-триггеры** (при отдыхе — «Слова исцеления», в фазу встреч — «Туманы
  Релеха», «Ясновидение») бросают проверку Знания тихо: кубы игроку не показываются,
  виден только итог.
- **«Защита плоти» / «Вселить отвагу»** срабатывают только в бою (окно между броском и
  «Завершить», как у бинтов). Потери вне боя — встречи, Мифы, Расплата — ими не
  предотвратить.
- 24 заклинания дополнений не сверены с вики (сверен только сезон 0).

### Сезон 0, по картам

| Заклинание | Упрощение |
|---|---|
| Благословение Исиды | Лицо: «сыщик на вашей клетке без Благословения» → сам кастующий. |
| Слова исцеления | Лицо: «сыщик на вашей клетке отдыхает» → только вы. |
| Сотворение | Лицо: цена вещи не ограничена результатом, Безделушки не учитываются. Оборот 2 (2+): «сколько угодно вещей на сумму результата» → одна вещь. Оборот 3 (4+): «артефакт вместо актива» → артефакт в дополнение. |
| Пища для разума | Оборот 4 (0): «сбросьте все жетоны улучшений, иначе — эту карту» — пусто (глагол `loseImprovement all` уже есть, данные не обновлены). |
| Ясновидение | Обороты 1 (3+) и 3 (1–2): ±1 кубик в исследовании — только текст. Оборот 2 (0): «сбросьте выбранную улику» → ближайшую. |
| Туманы Релеха | Оборот 4 (0–1): «на 1 кубик меньше в фазу встреч» — только текст. |
| Защита плоти / Вселить отвагу | Обороты 3+: «предотвратите до результата проверки» → до 3. «Тот сыщик» в оборотах → кастующий. |
| Проникнуть в пустоту | Лицо: «сыщик по вашему выбору перемещается» → вы. Оборот 3 (0): «и переместитесь на случайную клетку» — не выполняется. |
| Ядовитый туман | Лицо: «монстры с суммарной стойкостью» → один монстр. Оборот 4 (3+): «стойкость −1» → +1 успех. Оборот 4 (0): «бой с каждым монстром на клетке» — не выполняется. |
| Иссушение | Оборот 1 (3+): «монстр теряет здоровье по результату» — не выполняется. Оборот 2 (2+): «каждый ДРУГОЙ монстр» → каждый на клетке. Оборот 4 (0–1): «бой с каждым монстром» — не выполняется. |
| Увядание | Оборот 4 (2+): «урон монстра −1» — не выполняется. |

## Состояния

### Не хватает

24 состояния из дополнений (76 оборотов): 18 Талантов (Attuned, Composed, Elusive,
Guts, Headstrong, Martial Prowess, Meditation, Moxie, Perceptive, Practiced, Quick
Study, Relentless, Resilient, Rugged, Silver Tongued, Skulduggery, Studious, Visions),
Blight, Corruption, Living Link, Promise of Power, Terror, Wanted. Под Таланты нужна
новая механика (вид «talent», «переверните, чтобы…»).

Пока их нет, ссылки на них заменены: «Порча (Blight)» → состояние вида «Порча»,
«Розыск (Wanted)» → вид «Преследование», «Талант» → вид «Талант» (такой карты нет —
эффект пустой).

**«Король в жёлтом» (артефакт) — в черновике CMS**, в игру не выгружается: и пассив
(+2 ко всем навыкам при «Порче»), и Расплата («получите Порчу») держатся на состоянии
Blight, которого нет. Вернуть в published, когда заведём Blight (тип condition в CMS).
Движок теперь сам не кладёт в руку неизвестный id состояния (карта-фантом) —
gainCondition с таким id пропускается с предупреждением в консоли.

### Общее

- **Проверки в оборотах «Задержан» и «Затерян»** (вместо встречи) — видимые, как в
  Расплате. Но копия оборота закреплена за картой: «Переохлаждение» после «сбросьте и
  получите новое» возвращается на лицо с тем же оборотом, а не тянет новый.
- **«Помазанник» / «Осквернённый» / «Избранник»**: не проверяется, что у выбранного
  сыщика ещё нет такой карты; «Избранник» даёт Дар только вам.
- **«Сбросьте любое число состояний»** (Безмятежность, Что нас не убивает) — одно, по
  выбору.
- **«Закройте врата по выбору»** (Союз Серебряных Сумерек) — врата на вашей клетке.
- **«Продвиньте активную Тайну»** (Расплата Сэнфорда, Удар на опережение) — жетон на
  карту Тайны; для Тайн без счётчика жетонов не действует.

## Сыщики

- **Клайв Эштон**, пассив «1 рассудок вместо 1 улики»: в ценах карт и встреч
  срабатывает сам, только когда улик не хватает. Заплатить рассудком при запасе улик
  можно лишь в его действии (галка) и при перебросе (жетон «Цена прозрения»).
